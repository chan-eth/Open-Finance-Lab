# Phase 2 Projects

These projects focus on developing trading strategies and backtesting them on historical data.

---

## 📁 Projects

### 1. strategy-lab/
Jupyter notebooks for experimenting with indicators and strategies.

**What you'll build:**
- Notebooks for testing technical indicators
- Strategy prototypes
- Visual analysis of patterns
- Parameter optimization experiments

**Start here** if you prefer interactive development and visualization.

---

### 2. backtester-v1/
A simple but functional event-driven backtesting engine.

**What you'll build:**
- Core backtesting framework
- Support for long/short positions
- Transaction cost modeling
- Performance metrics calculator
- Trade history logger

**This is essential** - every serious trader needs backtesting infrastructure.

---

### 3. paper-trader/
Simulate live trading with real-time prices but no real money.

**What you'll build:**
- Connect to real-time price feeds
- Execute simulated trades
- Track paper portfolio
- Log all decisions
- Performance tracking

**Bridge between backtesting and live trading** - test strategies in real-time without risk.

---

## 🎯 Recommended Order

1. **Start with strategy-lab** - Explore and prototype ideas
2. **Build backtester-v1** - Test strategies on historical data
3. **Deploy paper-trader** - Validate strategies in real-time

---

## 💡 Integration

These projects are designed to work together:

```
strategy-lab (develop) → backtester-v1 (validate) → paper-trader (test live)
```

Strategies developed in notebooks can be:
1. Backtested with historical data
2. Paper traded with live data
3. Eventually deployed for real trading (Phase 3)
