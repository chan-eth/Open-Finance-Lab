# Phase 0 – Setup & Foundations

**Goal:** Go from "I've never coded" to "I can run simple Python scripts and use an API."

---

## 📋 Learning Checklist

- [ ] Install Python 3.10+ on your system
- [ ] Set up a code editor (VS Code, Cursor, or similar)
- [ ] Learn basic terminal/command line navigation
- [ ] Create a GitHub account and learn git basics
- [ ] Clone this repository to your local machine
- [ ] Run your first Python script
- [ ] Make your first API call
- [ ] Understand environment variables and API keys

---

## 📚 Lessons

### 1. Development Environment Setup

**What you'll learn:**
- Installing Python and pip
- Choosing and setting up a code editor
- Installing VS Code or Cursor
- Setting up terminal/command line

**Resources:**
- [Python Download](https://www.python.org/downloads/)
- [VS Code Download](https://code.visualstudio.com/)
- [Cursor Download](https://cursor.sh/)

**Verification:**
```bash
python --version  # Should show Python 3.10+
pip --version     # Should show pip version
```

---

### 2. Git & GitHub Basics

**What you'll learn:**
- What is version control?
- Creating a GitHub account
- Basic git commands: clone, add, commit, push
- Understanding branches and repositories

**Essential Commands:**
```bash
git clone <repo-url>
git status
git add .
git commit -m "message"
git push
```

**Practice:**
- Clone this repository
- Make a small change
- Commit and push to a new branch

---

### 3. Command Line Basics

**What you'll learn:**
- Navigating directories (cd, ls, pwd)
- Creating files and folders
- Running Python scripts
- Understanding file paths

**Essential Commands:**
```bash
pwd                    # Print working directory
ls                     # List files
cd <directory>         # Change directory
mkdir <folder>         # Make directory
python script.py       # Run Python script
```

---

### 4. Python Basics

**What you'll learn:**
- Variables and data types
- Basic operations
- Print statements
- Comments

**First Script:**
```python
# This is a comment
name = "Finance Lab"
print(f"Welcome to {name}!")
```

---

### 5. Working with APIs

**What you'll learn:**
- What is an API?
- HTTP requests (GET, POST)
- Reading JSON responses
- Environment variables for API keys

**Key Concepts:**
- API endpoints
- API keys and authentication
- Rate limits
- Response status codes

---

### 6. Effective AI Prompting

**What you'll learn:**
- How to ask AI assistants for help
- Breaking down problems
- Understanding AI-generated code
- Debugging with AI assistance

**Best Practices:**
- Be specific about what you want
- Provide context and constraints
- Ask for explanations, not just code
- Iterate and refine prompts
